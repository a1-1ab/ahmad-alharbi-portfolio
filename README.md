## 📌 About

This is my personal portfolio website, built to showcase my skills, projects, and journey as a front-end developer. It features:

- **Responsive design** for all screen sizes
- **Clean, modular code** with vanilla JavaScript
- **Dynamic content rendering** from a single source of truth (`portfolio-data.js`)
- **Modern UI** with smooth animations and a professional aesthetic

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Custom properties, Flexbox, Grid)
- **Vanilla JavaScript** (ES6+)
- **Git & GitHub** for version control
- **Netlify** for hosting

---

## 📂 Project Structure

```
ahmad-alharbi-portfolio/
├── index.html          # Main HTML file
├── css/               # Stylesheets
│   ├── tokens.css     # Design tokens (colors, spacing, etc.)
│   ├── reset.css      # CSS reset
│   ├── components.css # Reusable components
│   ├── sections.css   # Section-specific styles
│   ├── animations.css # Animations
│   └── responsive.css # Responsive styles
├── js/                # JavaScript files
│   ├── portfolio-data.js # Portfolio content (single source of truth)
│   ├── renderer.js      # DOM builders
│   └── main.js          # App entry point
└── README.md           # This file
```

---

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/a1-1ab/ahmad-alharbi-portfolio.git
   cd ahmad-alharbi-portfolio
   ```

2. **Open `index.html` in your browser:**
   - Simply open the file in your preferred browser.
   - No build step or server required!

---

## 📝 Customization

To customize the content of the portfolio:

1. Edit the `js/portfolio-data.js` file to update:
   - Personal information (name, bio, email, GitHub link)
   - Stats (LeetCode, certifications, etc.)
   - Skills and projects

2. Modify the styles in the `css/` directory to change the appearance.
